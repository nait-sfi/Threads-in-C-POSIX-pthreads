POSIX Threads & Mutexes in C
Clear concepts + under-the-hood behavior

1) Mental model of threads in one process

Shared by all threads

Code segment, heap allocations, global/static variables, open file descriptors.

Private per thread

Registers, program counter, stack, thread ID, TLS pointer.

Under the hood: On Linux, pthread_create() eventually uses a clone()-family kernel path so the new task shares address space with the parent thread.

2) Thread APIs + what happens underneath

pthread_create(pthread_t *t, const pthread_attr_t *a, void *(*start)(void *), void *arg)

What it does

Creates a new thread that starts at start(arg).

Under the hood

libpthread allocates stack/TCB, sets attributes, enters kernel to register a schedulable task.

Common pitfalls

Passing pointer to short-lived stack data; forgetting to join/detach later.

pthread_join(pthread_t t, void **retval)

What it does

Waits until target thread exits and collects its return value.

Under the hood

Caller blocks; kernel wakes it when thread state transitions to terminated.

Common pitfalls

Joining same thread twice; circular waits that can deadlock.

pthread_detach(pthread_t t)

What it does

Makes thread non-joinable; resources are released automatically on exit.

Under the hood

Thread metadata is marked detached, so no join handshake is expected.

Common pitfalls

Detaching then trying to join; losing error/return info from worker.

3) Why race conditions happen

The expression counter++ is not a single CPU step; it is logically load + add + store. Two threads can interleave these steps and overwrite each other.

Without lock (broken)

  1. Thread A loads counter=5
  2. Thread B loads counter=5
  3. A stores 6, then B stores 6
  4. One increment is lost

With mutex (correct)

  1. Thread A locks mutex, updates counter, unlocks
  2. Thread B waits, then enters critical section
  3. Updates are serialized
  4. No lost increments

4) Mutex APIs + under-the-hood details

pthread_mutex_init / pthread_mutex_destroy

What it does

Initialize and tear down a mutex object.

Under the hood

Sets internal state and attributes (normal/errorcheck/recursive where supported).

Common pitfalls

Destroying while locked or while another thread may still use it.

pthread_mutex_lock / pthread_mutex_unlock

What it does

Acquire and release exclusive access to critical section.

Under the hood

Fast path: atomic CAS in userspace.
Contended path: thread sleeps via futex; unlock wakes waiter(s).

Common pitfalls

Forgetting unlock on error path; locking in inconsistent order causing deadlock.

pthread_mutex_trylock

What it does

Attempts lock without blocking; returns EBUSY if already held.

Under the hood

Only attempts immediate atomic acquisition; no wait queue sleep on failure.

Common pitfalls

Busy-looping without backoff; using as if it guarantees fairness.

Memory ordering note: successful lock/unlock pairs provide synchronization edges so writes in one critical section become visible to the next lock holder.

5) Typical execution timeline

Main thread:
  pthread_create(T1)
  pthread_create(T2)
  pthread_join(T1)
  pthread_join(T2)

T1:
  lock(m)
  shared_counter++
  unlock(m)
  return

T2:
  lock(m)   // may block if T1 holds m
  shared_counter++
  unlock(m)
  return

The scheduler can switch at almost any point outside atomic operations; mutexes force safe serialization around shared state.

6) Complete example (safe counter)

#include <pthread.h>
#include <stdio.h>
#include <stdlib.h>

#define THREADS 4
#define LOOPS   250000

typedef struct s_shared {
    long counter;
    pthread_mutex_t m;
} t_shared;

void *worker(void *arg) {
    t_shared *s = (t_shared *)arg;
    for (int i = 0; i < LOOPS; i++) {
        pthread_mutex_lock(&s->m);
        s->counter++;
        pthread_mutex_unlock(&s->m);
    }
    return NULL;
}

int main(void) {
    pthread_t th[THREADS];
    t_shared s = {0, PTHREAD_MUTEX_INITIALIZER};

    for (int i = 0; i < THREADS; i++) {
        if (pthread_create(&th[i], NULL, worker, &s) != 0) {
            perror("pthread_create");
            return 1;
        }
    }
    for (int i = 0; i < THREADS; i++) {
        if (pthread_join(th[i], NULL) != 0) {
            perror("pthread_join");
            return 1;
        }
    }
    printf("counter=%ld expected=%d\n", s.counter, THREADS * LOOPS);
    pthread_mutex_destroy(&s.m);
    return 0;
}
